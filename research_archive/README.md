# Research Archive

This directory preserves internal evaluation history, forensic audits,
intermediate runs, and researcher notebooks that are not the official final
result.

`development_evaluation/archive_manifest.json` records original paths, sizes,
and SHA-256 hashes for the moved artifacts. Historical file bytes are retained
unchanged. Run identifiers remain in directory names where they are required
for provenance.

The official completed evaluation is intentionally separate at
[`evaluation/results/formal_run_2d5f0124`](../evaluation/results/formal_run_2d5f0124/).
Its headline metrics and artifact hashes are documented in
[`evaluation/results/README.md`](../evaluation/results/README.md).

Archived results are diagnostic and historical evidence. They must not be
combined with, resumed into, or reported as the official final evaluation.
